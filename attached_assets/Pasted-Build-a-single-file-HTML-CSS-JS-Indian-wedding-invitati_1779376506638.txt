Build a single-file HTML/CSS/JS Indian wedding invitation webpage with NO backend or database. All data is hardcoded. Use Three.js (CDN) for 3D animations and GSAP (CDN) for scroll and timeline animations. Tone: royal, sacred, warm, South Indian aesthetic.

━━━ OPENING CEREMONY (Full Screen Gate) ━━━
- Full-screen royal temple door: two tall carved wooden doors rendered in 3D using Three.js, with gold-embossed relief patterns (lotus, peacock, kalash motifs).
- Doors are CLOSED on page load. A soft glow pulses around the door frame.
- Below the door: animated text "✦ Click to open ✦" with a gentle heartbeat pulse.
- On click: doors swing open with a realistic 3D hinge animation (perspective transform + Three.js rotation).
- As doors open simultaneously trigger:
  → Nadaswaram/temple bell sound using Web Audio API (synthesized, no external file).
  → Floating diya particles (orange flame glows) rise from bottom.
  → White jasmine petal particles fall from top (CSS particle system, 60+ petals).
  → Couple names ("Priya & Arjun") appear center-screen with golden glowing text reveal (letter by letter).
  → Sacred Sanskrit quote appears below with fade-in: "सर्वे भवन्तु सुखिनः" with English translation.
  → "Enter Invitation ✦" button appears with shimmer border animation.
- Transition: doors dissolve into hero section with crossfade.
